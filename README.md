# De Buurt BBQ Muziekquiz

Open `index.html` in je browser om de quiz te spelen. Er zijn 30 gevarieerde vragen, één per scherm, met muziek uit de jaren 70 tot en met nu.

De quiz gebruikt ingebouwde Spotify-players. Spotify kan vragen om in te loggen; de precieze afspeelmogelijkheden hangen af van het Spotify-account en apparaat van de gebruiker.
